# FitCoach — 会员系统 + 支付系统 集成文档

> 涉及仓库：FitCoachServer、FitCoachRN、FitCoachAdminManager
> 阶段：MVP（一次性买断 + 微信 mock 通道 + Apple IAP 占位）

---

## 一、目标与边界

### 1. 业务目标

把"动作训练"从全部免费切到"少量免费 + 大部分会员可玩"。同时建立可演进的支付与会员体系：

- 会员**一次性买断**（不做自动续订），售卖周/月/季/年/永久 5 档套餐；
- 通道按平台路由：Android = 微信，iOS = Apple IAP；海外通道（Stripe/Google Play）以接口形式预留；
- Admin 后台可查看会员开通情况、订单与回调日志，可指定动作免费/会员；
- 客户端做"展示侧"和"启动训练前"的会员校验，**Server 是会员判定的唯一权威**。

### 2. 模块边界

| 模块 | 职责 |
|------|------|
| `fitcoach-exercise` | 动作元信息（key、肌群、是否免费）、按肌群保留 1 个免费动作的保护机制 |
| `fitcoach-membership` | 套餐、用户会员状态、`@TransactionalEventListener` 监听支付成功事件激活会员 |
| `fitcoach-payment` | 订单、支付通道路由、`PaymentChannelProvider` SPI、回调日志、PlanSnapshot 解耦 |
| `fitcoach-common` | `PaymentSucceededEvent`（事件 DTO 放公共模块避免循环依赖） |
| `fitcoach-app` | `DataInitializer` 灯种子（5 套餐 + 8 动作 + payment 配置） |
| `fitcoach-admin` | 4 个 Admin Controller（exercise / plan / membership / order） |

> **核心解耦原则**：`fitcoach-payment` 不依赖 `fitcoach-membership`。
> 支付成功后，PaymentService 发布 `PaymentSucceededEvent`，
> MembershipService 用 `@TransactionalEventListener(phase = AFTER_COMMIT)` 异步激活会员。
> 事件载荷包含 `PlanSnapshot`（套餐快照），即使 plan 在售卖期间被改价也不影响已下单订单。

## 二、错误码

新增两段错误码：

| 区段 | 含义 |
|------|------|
| `7501-7599` | 动作 / 会员 / 套餐相关业务异常（套餐不存在、套餐下线、用户已是会员等） |
| `8001-8199` | 支付 / 鉴权异常 |

特别约定：

- **`8001 MEMBERSHIP_REQUIRED`**：业务接口（如 `POST /api/exercise/start`）发现用户不是会员且动作非免费时抛此码。客户端 `httpClient` 全局拦截，调用注入的 `setMembershipRequiredHandler` 跳会员中心。

## 三、Server 端

### 1. fitcoach-exercise

- `Exercise` 实体：`exerciseKey`（业务唯一）、`muscleGroup`、`free`、`enabled`、`displayName` 等；
- `ExerciseService`：
  - `listAllEnabled()` —— 客户端拉动作列表；
  - `listFreeKeys()` —— 仅返回 free=true 的 key 集合，配合客户端"角标 + 启动校验"；
  - `setFree(key, free)` —— admin 调，**附带"按肌群保留至少 1 个免费动作"保护**：
    试图把某肌群最后一个免费动作改成付费，直接抛 `7503 LAST_FREE_IN_GROUP` 拒绝。

### 2. fitcoach-membership

- `MembershipPlan`（`planCode` 业务主键 + `priceCny` int 分 + `durationDays`）；
- `UserMembership`（`uid` + `expireAt`，永久套餐 expireAt 设很远的未来）；
- `MembershipService`:
  - `myStatus(uid)` 返回 `MembershipStatusDto{isActive, planCode, expireAt}`；
  - `@TransactionalEventListener(phase = AFTER_COMMIT)` 监听 `PaymentSucceededEvent`，按 PlanSnapshot 计算 expireAt 并 upsert UserMembership（取 max(now, prevExpireAt) + duration，叠加续费天数）；
- 提供 `MembershipCenterDto`（plans + status 一次性返回）减少首屏请求数。

### 3. fitcoach-payment

- `PaymentOrder`（`orderId` + `uid` + `channel` + `status` + `planSnapshot`）；
- `PaymentCallbackLog`（保留原始 payload，便于回放对账）；
- `PaymentChannelProvider` 接口（`createPay`、`verifyNotify`、`channelCode`）；
  - `WeChatPaymentProvider` —— 占位（V2 SDK 接入点 TODO）；
  - `MockPaymentProvider` —— 配置项 `payment.mock.enabled=true` 时启用，`createPay` 直接返回 `immediatelyPaid=true`，PaymentService 立即标记订单已支付并发事件；
  - `AppleIAPProvider` —— 占位（V2 实现 receipt 校验 + sandbox 切换）；
- `PaymentService`：
  - `createOrder(uid, planCode, channel)` —— 路由到对应 provider，返回 `CreateOrderResponseDto{orderId, channel, immediatelyPaid, payParams}`；
  - `mockNotify(orderId)` —— 仅 dev/sit 暴露，给 RN 联调用：模拟通道回调，幂等；
  - `cancelOrder(orderId)` —— 仅 PENDING 可取消；
- 配置 key 集中在 `PaymentConfigKeys`（`payment.mock.enabled` / `payment.wechat.appId` / ...），admin 后台可改。

### 4. RN 客户端 API（Controller）

| 路径 | 含义 |
|------|------|
| `GET /api/exercise/list` | 动作元信息（含 free 标） |
| `GET /api/exercise/free-keys` | 免费动作 key 集合（轻量，客户端做 7 天 TTL 缓存） |
| `POST /api/exercise/start` | 启动训练前校验，付费动作 + 非会员 → `8001 MEMBERSHIP_REQUIRED` |
| `GET /api/membership/center` | 套餐 + 当前会员状态（首屏一次性拉） |
| `GET /api/membership/my` | 当前会员状态（轻量） |
| `POST /api/payment/order` | 创建订单 |
| `POST /api/payment/mock-notify` | 模拟支付回调（仅 mock 通道） |
| `POST /api/payment/order/cancel` | 用户主动取消 PENDING 订单 |
| `GET /api/payment/orders` | 我的订单分页 |

### 5. Admin 后台 API

| 路径 | 含义 |
|------|------|
| `GET /api/admin/exercise/list` | 列动作（admin 视角包含 enabled=false） |
| `POST /api/admin/exercise/{id}/free` | 切换某动作免费态（含保护） |
| `GET /api/admin/membership/plans` | 套餐管理 |
| `POST /api/admin/membership/plan` | 新建/更新套餐 |
| `GET /api/admin/membership/users` | 会员开通用户分页 |
| `GET /api/admin/payment/orders` | 订单列表分页（按 status / channel / 时间筛选） |
| `GET /api/admin/payment/callback-logs` | 回调日志 |

### 2. httpClient 8001 拦截（反向解耦）

`src/common/http/httpClient.ts`：

```ts
const RESULT_CODE_MEMBERSHIP_REQUIRED = 8001;

let _membershipRequiredHandler: (() => void) | null = null;

export function setMembershipRequiredHandler(h: (() => void) | null) {
  _membershipRequiredHandler = h;
}

// rawRequest 解析 server result.code 时：
if (code === RESULT_CODE_MEMBERSHIP_REQUIRED) {
  _membershipRequiredHandler?.(); // 不吞错，仍然 throw ApiError
}
```

`App.tsx` / `RootNavigator.tsx` 注入：

```tsx
React.useEffect(() => {
  setMembershipRequiredHandler(() => {
    if (!navigationRef.isReady()) return;
    const cur = navigationRef.getCurrentRoute()?.name;
    if (cur === 'Membership' || cur === 'Payment') return; // 防死循环
    navigationRef.navigate('Membership');
  });
  return () => setMembershipRequiredHandler(null);
}, []);
```

> 这样设计的好处：`common/http` 不知道任何业务模块，避免循环依赖；同时业务侧仍能拿到 `ApiError(8001)` 做局部处理（比如训练页弹"会员专享"再跳转）。

### 3. 客户端会员校验

启动训练前的校验入口在 `src/training/screens/TrainingScreen.tsx#handleStartWorkout`：

```tsx
if (!isExerciseFree(exercise) && !isMember()) {
  Alert.alert('会员专享',
    `${exerciseInfo.displayName} 是会员专享动作`,
    [
      { text: '稍后再说', style: 'cancel' },
      { text: '查看会员', onPress: () => navigation.navigate('Membership') },
    ],
  );
  return;
}
```

> **降级原则**：`isExerciseFree` 在 free 集合尚未加载或为空时**默认返回 true（按免费处理）**，避免误拦。Server 端业务接口会用 8001 做权威兜底。

### 4. 动作角标三态

`src/training/screens/ExerciseListScreen.tsx`：

```tsx
const free = isExerciseFree(item.key);
const accessible = free || isMember();
const badge = free ? '免费' : (accessible ? 'VIP' : '会员');
```

### 5. 启动顺序（App.tsx）

1. `Monitor.init`（顶层）；
2. `tts.init`（最早，挂在 useEffect 里）；
3. `UserManager.init` —— 恢复登录态；
4. **已登录** → `refreshMembershipStatus()`（失败不阻塞）；
5. **任何用户** → `loadExerciseFlags()`（命中本地 7 天 TTL 缓存直接返回）；
6. `LoginInterceptor.registerNavigator`；
7. `useUserStore.subscribe` —— 同步给 Monitor。

### 6. 登出清理

`src/login/loginManager.ts#logout`：

```ts
await UserManager.logout();
clearMembershipStatus();
await clearExerciseFlagsCache();
```

避免下一个用户登录前 UI 还残留前一个用户的"会员中"标记和动作集合。

## 六、关键工程约定

| 约定 | 说明 |
|------|------|
| 金额最小货币单位 | 永远用 `int 分`/`int 美分`，禁止 `double`。展示侧用 `formatCnyFromCents` |
| `Page` 序列化 | server 直接序列化 Spring Data `Page`，含 `content/number/size/totalElements/totalPages/first/last`；client 用 `PageResponseDto<T>` 接住 |
| 配置项落库 | `payment.mock.enabled` / `payment.wechat.*` 走 `SysConfig`，admin 可改，无需改代码重启 |
| Flyway | 暂不引入，依赖 JPA `ddl-auto=update` —— **生产升级前先在 staging 校对差异** |
| 时间 | server 端 `LocalDateTime` + `ZoneId.of("Asia/Shanghai")` 序列化 epochMillis；client 端用 `Date(epochMillis)` 即可，无时区问题 |
